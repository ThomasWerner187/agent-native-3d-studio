# Superseded Chrome capture plan

This was an intermediate plan for recording a full Chrome window with an external ChatGPT sidebar. It was superseded by the final functional **Demo browser** take recorded from application revision `419e5554`.

The delivered film uses a deliberately small, visibly labelled browser bar and agent sidebar. The person types there, while the page displays receipts only for actual native WebMCP results. The film does not reproduce or claim Chrome or ChatGPT branding. See [FINAL-REVIEW.md](FINAL-REVIEW.md) and [CAPTURE-FORMAT.md](CAPTURE-FORMAT.md) for the final evidence.
